# Ruposhi International — Customer Storefront & B2B Portal (No Admin Panel)

This package includes **both**:
1. **Flutter (Web & Mobile) Project (`lib/`, `pubspec.yaml`)**: Built with Clean Architecture & `flutter_bloc` (`Cubit`) containing only the customer storefront and gated B2B Wholesale portal (`aaaa` / `aaaa`).
2. **Standalone Web Demo (`web_standalone/index.html`)**: A ready-to-open single-page HTML/Tailwind/JS build without the Admin Panel so you can preview it immediately in any browser.

## How to Run the Flutter App on Your PC
1. Extract this `.zip` file into your workspace folder.
2. Open a terminal inside the extracted folder and run:
   ```bash
   flutter create .
   flutter pub get
   flutter run -d chrome
   ```
